## Purpose

Set up a reproducible local-only Rust workspace with **untrusted public format shape validation** and deliberate **fail-closed cryptography stubs**. The purpose is architecture verification and early invalid-input safety, **not** usable secret storage. Keep all cloud, multi-device, remote rewrap, recovery, biometric, Shadow and Specter functionality unimplemented.

## M4 checkpoint (2026-10-31)

`encrypt_authenticated` seals `kind || schema || payload` with XChaCha20-Poly1305 under `ObjectKey`. Plaintext must be 2..=1,048,576 bytes before AEAD runs. The release nonce is 24 bytes from `getrandom` 0.4.3. `seal_object_with_nonce` exists only in `cfg(test)`.

The known-answer ciphertext is the output of `crates/test-vectors/scripts/object_aead_kat.py` (PyNaCl 1.6.2) and is stored in `crates/test-vectors/src/object_aead.rs`. Wrong key, AAD, ciphertext, and tag mutations, and truncated ciphertext, all return `Unavailable`.

**Nonce decision (2026-10-31):** every release seal draws a new 24-byte OS nonce. The cipher does not echo a previous nonce and ciphertext when the plaintext is repeated, and it does not reject a second plaintext by comparing ciphertexts. Storage idempotency, if added, is keyed by object id and a plaintext content hash. See [09_ENVELOPE_FORMAT_V0.md](09_ENVELOPE_FORMAT_V0.md).

`status()` remains `NotImplemented`. Key `Drop` zeroizes and is documented as best-effort.

## M5.20 checkpoint (2026-10-31)

`check_genesis_predecessor` in `eidoron-vault` applies one rule to a decrypted body: kind `0x01`, schema `0x00`, generation 0, and a null predecessor. A byte string at generation 0, including length 0, is rejected. The function does not validate map keys 2 and 3 and does not judge generation greater than 0. Fixtures and expected labels are the output of `crates/test-vectors/scripts/genesis_commit_kat.py`.

**Storage hash decision (2026-10-31):** an idempotency content hash must be keyed (HMAC, keyed BLAKE, or HKDF from vault secrets) or stored encrypted. A plain hash of plaintext is forbidden. See [09_ENVELOPE_FORMAT_V0.md](09_ENVELOPE_FORMAT_V0.md).

## Multi-chunk file checkpoint (2026-11-01)

`append_directory` writes an empty subdirectory object and links it. A file entry in that call is rejected and the folder is unchanged. `write_file` stores an empty payload as zero chunks. Larger payloads split at 1,048,554 bytes, up to 8192 chunks. Each chunk is checked on write and again on read. `read_file` returns plaintext only after every chunk verifies. A missing chunk is `Unavailable` while `status` stays `Ok`. A tampered chunk fails decrypt, so `status` is `Unavailable` and no plaintext is returned. `replace_file` adds a new descriptor and commit and leaves the old descriptor bytes in place. `write_file` on that name is `DuplicateName`. `delete_entry` unlinks the name and leaves the descriptor file. `select_head` does not change the folder. Conflict-copy bytes stay put. No new ciphertext vector was added.

On rustc 1.99.1, `cargo fmt --all -- --check`, `cargo test --workspace --locked --offline` (58 unit tests) and `cargo clippy --workspace --all-targets --locked --offline -- -D warnings` exited 0.

## Missing-chunk status and streaming read (2026-11-01)

A sole head, or the selected head while forked, is `Incomplete` when a reachable file's descriptor or chunk file is absent. `entries` lists those file names. Putting the chunk file back makes a sole complete head `Ok`. A ciphertext that is present but does not decrypt is `Unavailable` for `status` and for both read APIs. `read_file_chunks` returns a chunk only after AEAD and `check_chunk_identity` accept that manifest index. Truncation, a repeated chunk id, and a wrong ordinal are `Unavailable` and that chunk is not returned. `read_file` still returns the whole file or nothing. Genesis writes an empty root directory object. Unreachable objects are not deleted. Conflict-copy bytes stay put. No new ciphertext vector was added.

## Fork status and metadata note (2026-11-01)

`Conflict` lists every head and a `waiting` vector of `{ head, name }` for files whose descriptor or chunk is absent. `Incomplete` is not used while two heads exist. Missing, tampered, truncated, duplicated, and reordered chunk cases are separate tests. [14_METADATA_LEAKAGE.md](14_METADATA_LEAKAGE.md) records the sync-folder view. A test checks that object names are 64 lowercase hex and that a chunk file is 126 bytes longer than its payload. Equal plaintexts do not share chunk bytes. Padding is not implemented.

## Last-chunk padding (2026-11-01)

Short last chunks are zero-padded to a power-of-two bucket of at least 4096 bytes, capped at 1,048,550. The unpadded length is authenticated in the chunk and checked against the descriptor size. Padding bytes must be zero. Streaming returns only the unpadded bytes. Schema `0x00` is rejected. [15_GC_POLICY.md](15_GC_POLICY.md) is policy only.
